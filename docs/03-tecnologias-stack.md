# FlashBlock v0.1

## Tecnologias e Stack

### 1. Objetivo

A primeira versão do FlashBlock será desenvolvida utilizando as tecnologias fundamentais da Web, sem a utilização inicial de frameworks ou bibliotecas de interface.

A escolha tem como objetivo consolidar os conhecimentos de **HTML, CSS e JavaScript** por meio da construção de uma aplicação real e utilizável.

Frameworks e outras tecnologias poderão ser incorporados posteriormente conforme as necessidades do projeto e a evolução do conhecimento do desenvolvedor.

---

## 2. Tecnologias

### HTML5

Responsável pela estrutura e semântica da aplicação.

Será utilizado para definir:

* estrutura das páginas;
* cartões;
* formulários;
* botões;
* campos de entrada;
* navegação;
* elementos semânticos.

### CSS3

Responsável pela apresentação visual e responsividade da aplicação.

Será utilizado para:

* layout;
* cores;
* tipografia;
* espaçamento;
* animações e transições;
* estados dos elementos;
* responsividade para diferentes tamanhos de tela.

### JavaScript

Responsável pelo comportamento e pela lógica da aplicação.

Será utilizado para:

* manipulação do DOM;
* eventos de interação;
* criação de cartões;
* navegação entre cartões;
* exibição e ocultação de respostas;
* exibição de dicas;
* controle do estado atual da revisão;
* validação de formulários;
* gerenciamento inicial dos dados.

---

## 3. Tecnologias inicialmente não utilizadas

A versão 0.1 não utilizará inicialmente:

* React;
* Vue;
* Angular;
* bibliotecas de componentes;
* frameworks CSS;
* TypeScript;
* backend;
* banco de dados;
* APIs externas.

Essa decisão é intencional e tem caráter educacional.

O objetivo é compreender e consolidar os fundamentos antes de introduzir abstrações fornecidas por frameworks e outras ferramentas.

---

## 4. Ambiente de desenvolvimento

O projeto será desenvolvido utilizando:

* Visual Studio Code como editor;
* Git para controle de versão;
* GitHub para armazenamento e versionamento do código;
* navegador moderno com DevTools para testes e depuração.

---

## 5. Estrutura inicial

A estrutura inicial do projeto será simples:

```text
FlashBlock/
│
├── index.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
├── assets/
│   ├── images/
│   └── icons/
│
└── README.md
```

A estrutura poderá ser modificada conforme o projeto crescer.

---

## 6. Evolução tecnológica

A adoção de novas tecnologias não será determinada antecipadamente.

Uma nova tecnologia deverá ser incorporada quando:

1. surgir uma necessidade real no projeto;
2. a tecnologia resolver adequadamente essa necessidade;
3. houver conhecimento suficiente dos fundamentos para compreender a abstração introduzida.

Um possível caminho futuro é:

**HTML + CSS + JavaScript**

↓

**JavaScript modular**

↓

**TypeScript**

↓

**Framework de interface**

↓

**Backend + banco de dados**

↓

**Autenticação**

↓

**Sincronização**

↓

**Integrações externas, como Google Drive**

Esse caminho não representa um cronograma obrigatório, mas uma possível evolução do projeto planejada pelo desenvolvedor.
